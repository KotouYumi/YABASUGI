# YABASUGI v0.14.2 — お知らせ・見出し位置修正版

直前の **v0.14.1** を基準にした限定修正です。

1. コンテンツの分類に「お知らせ」があることを確認（v0.14.1で追加済み、今回維持）。コンテンツ編集画面とトップページのカテゴリーフィルターで使用できます。
2. 記事内のピンク斜線入り装飾見出し（例：「デジタルビンゴ」）の文字開始位置を、PC・スマホともに左端から30%の位置に修正。装飾線の終端（約24%）と文字が重ならないよう、余裕を設けました。

## 変更範囲
`index.html` のCSSを2箇所だけ変更。JavaScript・既存のJSON・商品リンク・画像・ビンゴ音源・Firebase設定・バナー本体には変更を加えていません。

## 公開
ZIPを展開し、**同じフォルダ構成のまま** Vercel へ配置してください。Vercel側への公開操作はここでは実行していません。

## 確認したこと
- HTML内のカテゴリーデータに「お知らせ」が存在すること
- CSSで見出し文字の開始位置が装飾帯の終端より右にあること
- HTMLの差分が対象CSS2箇所のみであること
- JSONなど他の関連ファイルが同一であること

Firebase実接続、iPad Safari実機での動作検査はこの修正では行っていません。
